# Parakh - Frontend

The user interface of Parakh, built with Next.js and React.

It provides two experiences:

- **Citizen side** - report service issues, view alerts and pay for services.
- **Operator side** - review submitted requests, view an overview of activity and explore analytics.

## Getting Started

Install dependencies and run the development server:

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to see the app.
